# claude-deep-context

**Дайте Claude один раз проінтерв'ювати вас — і більше не пояснюйте все спочатку в кожному чаті.**
Скіл проводить структуроване інтерв'ю (14 блоків, по одному питанню) і перетворює відповіді на два скіли для claude.ai: **my-profile** (як ви працюєте, хто ви, сім'я й дати, спорт, техніка) і **my-company** (компанія, люди, договори, фінанси, проєкти).

🇬🇧 [English version](README.md)

## Два способи
| | Чат claude.ai | Claude Code / Cowork |
|---|---|---|
| Що потрібно | тариф зі Скілами | Claude Code (або Cowork) |
| Куди йдуть відповіді | лишаються в розмові; картка прогресу, щоб продовжити в новому чаті | після кожного блоку — у `profile/docs/ABOUT-ME.md` і `<компанія>/docs/CONTEXT.md` |
| Наприкінці | `my-profile.zip`, `my-company.zip` (або текст, щоб зберегти) | те саме, а файли-довідки лишаються на диску |

## Швидкий старт — чат claude.ai
1. Завантажте це сховище (зелена кнопка **Code** → **Download ZIP**) і розпакуйте.
2. Зробіть zip скіла: стисніть папку `skills/deep-context-interview` у `deep-context-interview.zip` (Windows: правою кнопкою → Надіслати → Стиснута ZIP-папка) або запустіть `python tools/build-skill-zips.py skills`.
3. claude.ai → ваше ім'я ліворуч унизу → **Налаштування** (Settings) → **Можливості** (Capabilities) → **Скіли** (Skills) → **Завантажити скіл** (Upload skill) → виберіть zip → увімкніть.
4. Новий чат: **«Проведи зі мною інтерв'ю»**. Відповідайте текстом, голосом чи файлами (резюме закриває цілий блок). Скажіть **«пауза»**, коли треба зупинитися.
5. Наприкінці так само завантажте два скіли, які він видасть. Готово: кожен новий чат (і Cowork) уже знає вас.

## Швидкий старт — Claude Code
Скопіюйте `skills/deep-context-interview/` у свою робочу папку як `.claude/skills/deep-context-interview/`, відкрийте там Claude Code і скажіть **«Проведи зі мною інтерв'ю»**. Або без скіла — вставте запит з [interview/questions.uk.md](interview/questions.uk.md).

## Що всередині
| Шлях | Що |
|---|---|
| `skills/deep-context-interview/` | скіл-інтерв'юер (самодостатній: усі питання й правила всередині) |
| `skills/my-profile/`, `skills/my-company/` | шаблони двох скілів-результатів |
| `interview/questions.md`, `questions.uk.md` | питання списком для читання (EN / UK) |
| `tools/build-skill-zips.py` | пакує папки скілів у zip, які приймає claude.ai; незаповнені шаблони не пакує |

## Приватність
Інтерв'ю ніколи не питає паролі, номери карток чи рахунків, паспортні дані й коди електронного підпису, а скіл відмовляється їх зберігати. Ваші скіли-профілі живуть у вашому обліковому записі claude.ai, файли-довідки — на вашому диску.

## Щоб пам'ять була свіжою
Скіли — це знімок. Щоб Claude Code, чат claude.ai і Cowork після кожної задачі знали те саме, дивіться сусідній набір **[claude-shared-memory](https://github.com/kuzubis/claude-shared-memory)**.
